# Core: Package (Resource)

Manages packages on a Synology NAS using the Package Center API.

Install, configure, and manage Synology packages with optional wizard configuration for initial setup.

## Example Usage

```hcl
# Install MariaDB with wizard configuration
resource "synology_core_package" "mariadb" {
  name = "MariaDB10"
  
  wizard = {
    port              = "3306"
    new_root_password = "secure-password"
  }
}

# Install Docker package
resource "synology_core_package" "docker" {
  name = "Docker"
}
```

## Example Usage

```terraform
resource "synology_core_package" "mariadb" {
  name = "MariaDB10"

  wizard = {
    port              = 3306
    new_root_password = "T3stP@ssw0rd"
  }
}

# `run` is the only attribute that can be changed in place: toggling it starts
# or stops the package through SYNO.Core.Package.Control. Every other attribute
# forces replacement, which uninstalls the package first -- and uninstalling a
# package can remove the data it owns.
resource "synology_core_package" "container_manager" {
  name = "ContainerManager"
  run  = false
}

# `volume_path` names the volume the package is installed onto. It is optional:
# when omitted, the volume is resolved from DSM's package settings -- its
# configured default if it has one, otherwise the NAS's only volume.
#
# Set it explicitly on a multi-volume NAS. With several volumes and no DSM
# default, omitting it is an error rather than an arbitrary choice: which volume
# a package lands on decides where its data lives, and DSM offers no way to move
# it afterwards. Changing it reinstalls the package for the same reason.
resource "synology_core_package" "plex" {
  name        = "Plex Media Server"
  volume_path = "/volume1"
}
```

## Schema

### Required

- `name` (String) The Package Center identifier of the package to install, for example `MariaDB10` or `ContainerManager`. DSM has no rename operation, so changing this uninstalls the current package and installs a different one. Uninstalling a package can remove the data it owns.

### Optional

- `beta` (Boolean) Whether to install beta versions of the package.
- `file` (String) The file to install.
- `run` (Boolean) Whether the package should be running. Toggling this starts or stops the package in place via `SYNO.Core.Package.Control`; it does not reinstall it. This is the only attribute on this resource that can be updated without replacement.
- `url` (String) The URL to the package to install.
- `version` (String) The package version. Changing it reinstalls the package, because DSM offers no in-place upgrade through this API.
- `volume_path` (String) The volume to install the package onto, for example `/volume1`. Optional. When omitted the volume is resolved from DSM's package settings: its configured default if it has one, otherwise the NAS's only volume. On a multi-volume NAS with no configured default, leaving this unset is an error rather than an arbitrary choice — which volume a package lands on decides where its data lives, and DSM offers no way to move it afterwards. Changing this reinstalls the package for the same reason.
- `wizard` (Map of String) Wizard configuration values, consumed only during installation.
